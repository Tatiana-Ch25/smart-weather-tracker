# Smart Weather Tracker

A responsive weather application that allows users to search for a city and view current weather conditions and a three-day forecast.

## Features

- Search for a city
- Display current temperature and weather conditions
- Show humidity, wind speed, visibility, and feels-like temperature
- Display a three-day weather forecast
- Switch between Celsius and Fahrenheit

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5.3.8
- JavaScript (ES6+)
- Open-Meteo API for geocoding and weather forecast data
- Git and GitHub
- GitHub Pages

- Fetching and handling data from external APIs

- Managing application state
